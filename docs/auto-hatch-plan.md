# 企畫書：自動孵蛋（Auto Hatch）

> 狀態：草稿（2026-07-30 建立）。遊戲內孵蛋規則細節待使用者補充，
> 見文末「注意事件紀錄區」。此文件先定調範圍與架構，不是實作規格。

## 1. 目標

新增第二種自動化功能：自動孵蛋。讓 bot 依遊戲的孵蛋規則自動完成
「收蛋 → 補蛋 → 等待」的循環，減少人工顧孵蛋槽的時間。

## 2. 範圍與定位

- **獨立功能，不與現有自動採集（Auto Hunt）混用。**
  - 各自有獨立的啟動方式（暫定：CLI 子命令或 `--feature hatch` 之類的旗標，待定）。
  - 各自有獨立的設定區塊、素材資料夾、統計計數。
  - 第一版**不做**兩功能同時執行或自動輪替；未來若要輪替（例如狩獵等待
    capacity 時順便去孵蛋），另開企畫。
- 沿用既有框架：`Sense → Think → Act → Verify` 回饋循環、既有的
  Capture / Detect / Action / Recover 基礎設施，以 Feature 方式加入，
  不修改核心狀態機（README 既有原則）。

## 3. 現況架構切入點（初步盤點）

| 既有模組 | 孵蛋功能的利用方式 |
| --- | --- |
| `engine.py` 狀態機（Idle/Capture/Detect/Planning/Action/Verify/Recover） | 直接沿用循環，換掉 Planner 與偵測目標 |
| `detection.py`（template matching / HSV / NMS） | 新增孵蛋相關 UI 素材（蛋槽、收取按鈕、完成標記等） |
| `planning.py` / `planner.py` | 新增 HatchPlanner：決定這一輪要收蛋、放蛋還是等待 |
| `recovery.py` / `stalls.py` | 沿用卡死逃生；孵蛋頁面的重置路徑需另外定義 |
| `status.py` / `status_server.py` | 新增孵蛋統計（收了幾顆、目前槽位狀態、下次可收時間） |
| `config.py` / `config.json` | 新增 `hatch` 設定區塊，與 hunt 設定分開 |

## 4. 流程（依 2026-07-30 使用者提供的截圖與說明確認）

1. **主頁面**（一切行為的起點）：以**固定座標**點擊下方偏中的大蛋堆平台
   （樣式會變，不做圖像辨識）。
   - Verify：看到「孵化器」標題畫面。
2. **孵化器格子頁**（最多 24 顆蛋，只需檢查頂部可見區）：
   找「蛋下方有『孵化』字樣」的蛋（黃光圈與否無差別）。
   - 找到 → 點第一顆，進入詳細頁（步驟 3）。
   - 頂部可見區沒有 → 不再下滑；遊戲會把可孵化蛋排在上方，
     因此可直接點 X 回主頁面，進入收蛋後冷卻分支。
3. **詳細頁循環**（核心迴圈，不用回格子頁）：
   a. 按青色「孵化」按鈕。
   b. 等過場動畫播完，等到結果頁出現「獲取」按鈕。
   c. 按「獲取」（**絕對不可誤點紅色「驅逐」**）。
   d. 自動切到下一顆蛋的詳細頁（計數遞減，如 1/24 → 1/23），回到 a。
   e. 可孵化的蛋處理完後，畫面會**自動回到孵化器格子頁**（計數可能歸零
      如 0/24，也可能還剩冷卻中的蛋，不一定全空）→ 偵測到又回到
      「孵化器」標題畫面就**按 X 關閉**，回主頁面。
4. **蛋巢管理**（Phase B，回主頁面後接著做）：
   a. 點左上選單第 4 個「蛋巢」→ 進「我的巢」。
   b. **攻擊特化輪**：標籤選「攻擊特化」→ 逐巢、逐親代（左右都要）：
      讀親代三圍 → 點親代開「選擇恐龍」→ 檢查標籤=所有、排序=攻擊力
      降冪（會保留上次設定，必檢）→ 攻擊比親代高才換（同攻擊挑
      生命+速度低的；冷卻中/星星都可選）→ 彈窗按「是」→ 回卡片。
      沒有更高的就跳過。
   c. **HP特化輪**：同 b，準則換成生命最高優先、排序選生命。
   d. **頂尖輪**：標籤選「頂尖」→ 點齒輪恐龍 → 下拉改選
      「最佳屬性組合」（會保留上次設定，必檢）→ 點黑遮罩關閉 →
      按底部「自動放置」→ 彈窗出現就按「是」。
   e. **量產輪**：標籤選「量產」→ 齒輪恐龍 → 下拉改選「等級」→
      黑遮罩關閉 → 「自動放置」→ 彈窗按「是」。
   f. **收尾**：標籤選回「所有」→ 按「收集所有的蛋」（跳「孵化器
      已滿。」提示就不管）→ 關閉「我的巢」回主頁面。
   g. **無可孵化蛋的補蛋分支**：若 Phase A 整輪孵化數為 0，
      關閉孵化器後只開啟「我的巢」、切回「所有」、按「收集
      所有的蛋」，關閉巢穴後冷卻 10 分鐘。這條分支不執行
      攻擊／HP 親代、頂尖／量產自動放置或 Phase C 清理。
5. **清除多餘恐龍**（Phase C，接在收集蛋之後、視數量觸發）：
   a. 回主畫面，滑動地圖（往下＋往左）到「有眼睛的洞穴」視角——
      此視角左上的恐龍數量 N/350 清晰可讀。
   b. 讀數量：**≤320 → 跳過清理**，直接回大循環；**>320 → 執行清理**。
   c. 點洞穴 → 按「選擇」→ 開「選擇恐龍」清單：標籤確認「所有」
      （會保留上次選擇，必檢）→ 按「選擇最弱恐龍」（遊戲自動勾
      預設數量，不用調）→ 按青色「選擇」（清單關閉）。
   d. 按「連續戰鬥」→ 等戰鬥動畫 → 結算畫面出現「獲取」→ 按「獲取」
      → 自動回到主畫面。
6. **回到步驟 1 重新跑孵化流程**——以 12 隻完成孵化為一個成長批次，
   未滿 12 隻時只收蛋並等待下一批，不進入巢穴篩選／管理；等待期間
   仍可執行狩獵。累積滿 12 隻才進行蛋巢管理。若孵化器裡沒有任何
   「孵化」字樣（全部倒數中）→
   按 X 關閉 → 開「我的巢」切回「所有」並收蛋 → 讀取目前畫面上可見
   倒數的最晚完成時間，等到該批接近完成後再從流程開頭檢查。OCR
   讀不到時才使用 `rescan_interval`（預設 10 分鐘）作為 fallback。
7. **結合狩獵模式**（獨立 `hatch-hunt`）：步驟 6 的冷卻開始後
   切換至 HuntPlanner；冷卻最後 30 秒不再開新的狩獵，先收尾當前
   畫面並執行地圖回中。只有孵蛋 home anchor 與狩獵中央蛋同時
   連續兩幀成立，才把控制權交回 FullHatchPlanner。兩個 planner 在
   同一引擎內交替，不允許兩個進程同時操作 ADB。
8. **洞穴點擊安全區**：洞穴 template 命中後，點擊中心必須通過
   HuntPlanner 同級的畫面邊界（預設左／右／上 80 px、底部 180 px）。
   落在底部對話與導覽區的命中只當作「洞穴不可見」，繼續受限
   定重掃，最後回中，絕不點擊。回中不使用底部箭頭，而是記錄實際
   完成的洞穴導航 swipe，再以相反順序與方向滑回，避免誤開聊天列／部落。

## 6. 素材需求（依已確認流程整理）

**Phase A 孵化：**
- 「孵化器」標題（格子頁 Verify 用）
- 蛋下方「孵化」標籤（格子頁點蛋目標）
- 詳細頁青色「孵化」按鈕
- 結果頁青色「獲取」、紅色「驅逐」（驅逐僅用於防呆排除）
- 紅色 X 關閉鈕
- 藍光圈倒數/進度條（「全部冷卻中」判斷輔助）

**Phase B 蛋巢管理：**
- 左上選單第 4 個「蛋巢」圖示（草巢白蛋）
- 「我的巢」標題、齒輪恐龍按鈕
- 標籤下拉展開態與各標籤項（所有/量產/頂尖/HP特化/攻擊特化，含色條）
- 「選擇恐龍」標題、排序欄位下拉與選項（攻擊力/生命…）、排序方向箭頭
- 確認彈窗青「是」／紅「否」（與獲取/驅逐分開建模板）
- 「自動放置」彈窗：排序下拉選項（最佳屬性組合/等級）、黑遮罩區座標
- 底部三鈕：使用信息素／自動放置／收集所有的蛋
- 「孵化器已滿。」黑色 toast（可辨識但不需處理）
- 0-9 數字模板（讀生命/攻擊/速度；卡片與清單兩種字級可能要各一套）

**Phase C 清除多餘恐龍：**
- 洞穴模板（灰石堆＋黑洞口＋黃眼睛＋白牙）
- 恐龍數量 N/350 讀取（洞穴視角左上，數字模板共用）
- 洞穴內「選擇」按鈕
- 清單底部「選擇最弱恐龍」「選擇」按鈕（清單版面與 Phase B 共用，
  但底部按鈕不同）
- 「連續戰鬥」按鈕（截圖待補）
- 戰鬥結算頁「獲取」按鈕（可能與孵化結果頁同款，實測確認）
- 主畫面下滑＋左滑的 swipe 參數（實測校準）

實際素材照 `assets/` 既有慣例建立獨立子資料夾（暫定 `assets/hatch/`）。

## 7. 風險與注意

- 孵蛋等待時間可能遠長於狩獵循環（分鐘～小時級），空轉偵測與卡死判定的
  門檻不能沿用 hunt 的數值，需獨立設定。
- 黑畫面暫停 Detect/Verify 的既有機制要確認在孵蛋頁一樣適用。
- 版本更新遊戲 UI 改版時，hatch 素材要能獨立更新，不影響 hunt。
