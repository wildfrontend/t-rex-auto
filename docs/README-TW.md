# Dino Mutant Bot 文字版使用教學

適用於 Windows 10／11。

支援 MuMu、BlueStacks，以及其他有提供 ADB Port 的 Android 模擬器。使用者不需要
選擇模擬器品牌，只要找到模擬器顯示的 ADB Port 並輸入即可。

> 請自行確認遊戲規則、帳號安全與使用風險。工具不會要求你的遊戲帳號或密碼。

## 一、下載哪個版本

### Lite 輕量版

- 壓縮檔較小。
- 已包含 ADB。
- 第一次執行時會下載 Python、OpenCV 與必要套件。
- 適合網路正常、希望下載檔案較小的使用者。

### Portable 完整免安裝版

- 已包含 ADB、Python、OpenCV 與必要套件。
- 解壓縮後即可執行，不需要另外安裝 Python。
- 適合不熟悉電腦操作，或電腦經常缺少執行檔案的使用者。

如果不知道該選哪一個，請使用 Portable 完整免安裝版。

## 二、解壓縮

請先將 ZIP 完整解壓縮，不要直接在壓縮檔內執行。

建議放在 D 槽根目錄，例如：

```text
D:\DinoMutantBot
```

請保留整個資料夾，不要只複製 `app` 資料夾。

## 三、設定模擬器畫面

1. 開啟模擬器。
2. 啟動 Dino Mutant。
3. 將模擬器解析度設為直向 `900 × 1600`。
4. 建議使用預設 DPI 與遊戲 UI 大小。
5. 讓遊戲停在主地圖或採集地圖。

解析度非常重要。如果不是 `900 × 1600`，可能會出現按鈕辨識不到、狩獵沒有按下，
或點擊位置偏移。

Bot 使用 ADB 在背景讀取畫面與點擊，不需要搶走滑鼠，也不要求模擬器保持在最上層。
模擬器與遊戲仍必須保持開啟，電腦不可進入睡眠。

## 四、尋找 ADB Port

每個模擬器顯示 ADB Port 的位置可能不同，通常位於：

- 設定
- 進階設定
- 問題診斷
- 網路資訊
- ADB 或 Android Debug Bridge

### MuMu

在 MuMu 的設定、問題診斷或網路資訊中尋找：

```text
ADB調試埠
```

例如畫面顯示：

```text
ADB調試埠  16384
```

啟動 Bot 時只要輸入：

```text
16384
```

不要輸入 MuMu 出口 IP，也不要輸入 DNS 或 MAC 位址。

### BlueStacks

先在 BlueStacks 設定中啟用 Android Debug Bridge，再查看它顯示的連線 Port。
若畫面顯示 `127.0.0.1:5555`，可以輸入：

```text
5555
```

### 其他模擬器

只要模擬器能開啟 ADB，並提供本機 ADB Port，就可以使用。啟動 Bot 時輸入該 Port，
不需要選擇品牌。

## 五、第一次啟動

1. 確認模擬器與 Dino Mutant 已經開啟。
2. 雙擊 Bot 資料夾內的：

```text
start-bot.cmd
```

3. 第一次啟動時，輸入模擬器顯示的 ADB Port。
4. 例如 MuMu 顯示 `16384`，就輸入 `16384` 後按 Enter。
5. 啟動器會自動檢查 ADB、遊戲畫面、辨識素材與執行環境。
6. 全部檢查通過後，Bot 才會開始執行。

Lite 版第一次啟動時會詢問是否下載必要套件，請依畫面指示允許下載。Portable 版不需要
下載 Python 或 OpenCV。

第一次輸入成功後，設定會保存在 Bot 根目錄：

```text
user-settings.json
```

以後啟動時直接按 Enter，就會沿用上次的 ADB Port。更新 `app` 資料夾時也會自動套回
這項設定。

如果改用新的 Bot 資料夾，可以將舊資料夾的 `user-settings.json` 複製到新資料夾，
或在第一次啟動時重新輸入 ADB Port。

## 六、控制視窗

啟動後會看到控制視窗與 LOG 視窗。

控制視窗可輸入：

```text
S  查看目前狀態與狩獵次數
M  更改模擬器 ADB Port
T  調整執行速度
P  更改本機狀態接口 Port
D  開啟診斷工具
E  產生诊斷 ZIP
A  顯示本機 AI 接口
R  重新啟動 Bot
Q  停止 Bot
```

一般使用時可以直接按 Enter，效果與輸入 `S` 相同。

### 更換模擬器或 ADB Port

如果重開模擬器後 Port 改變，或想切換到另一個模擬器：

1. 在控制視窗輸入 `M`。
2. 輸入新的 ADB Port。
3. Bot 會先檢查新設定。
4. 檢查成功後才會重新啟動並套用。
5. 如果檢查失敗，原本正在執行的設定會保留。

## 七、Bot 會自動做什麼

- 尋找安全的恐龍目標。
- 避開我方藍色路徑與底部操作區。
- 選擇恐龍、按下狩獵並確認。
- 隊伍滿額或目標太強時等待後再試。
- 定期回到地圖中央。
- 定期領取信箱獎勵。
- 處理常見的登入與啟動畫面。
- 畫面持續全黑超過 45 秒時，自動重啟 Dino Mutant App。
- 畫面正常但連續 180 秒沒有狩獵進度時，自動重啟 Dino Mutant App。

自動重啟只會關閉並重新開啟遊戲 App，不會關閉整個模擬器。隊伍滿額、沒有可用恐龍、
目標太強、登入、信箱與正常等待期間不會被當成異常。

使用者也可以明確要求隨附的 `control-dino-bot` Skill 重啟 Dino Mutant App。這個動作
透過 Bot 的本機白名單 API 執行，不需要操作 CMD 選單，也不會重啟整個模擬器。

## 八、如何停止

請回到控制視窗輸入：

```text
Q
```

看到停止完成後再關閉視窗。不要只關閉 LOG 視窗，否則控制程序可能仍在執行。

如果新版啟動時顯示已有另一個 Bot 正在執行，請先在舊控制視窗輸入 `Q`。

## 九、常見問題

### 顯示找不到 ADB 裝置

依序確認：

1. 模擬器已開啟。
2. 模擬器已啟用 ADB。
3. 輸入的是 ADB Port，不是 IP、DNS 或 MAC 位址。
4. Port 與目前這個模擬器實例顯示的數字相同。
5. 多開模擬器時，選到的是正在執行 Dino Mutant 的實例。
6. 在控制視窗按 `M`，重新輸入 Port。

### MuMu 顯示很多網路資料，要輸入哪一個

只輸入「ADB調試埠」後面的數字。

例如：

```text
MuMu DNS       192.168.0.1
Rom MAC地址    08:9c:ef:1f:b0:00
ADB調試埠      16384
MuMu出口IP地址 10.0.2.15
```

正確輸入是：

```text
16384
```

### 狩獵按鈕沒有按到或位置不準

1. 將模擬器設為直向 `900 × 1600`。
2. 確認沒有自行縮放遊戲 UI。
3. 讓 Dino Mutant 保持在遊戲畫面，不要停在模擬器設定頁。
4. 重新啟動 Bot。
5. 如果仍然發生，在控制視窗輸入 `E` 產生診斷包。

### 一直顯示沒有可操作目標

Bot 可能正在避開我方藍色路徑上的恐龍，或等待安全目標。這不一定是故障。若超過
180 秒仍無狩獵進度，Bot 會判斷畫面可能異常並自動重啟遊戲。

### 顯示 ADB executable not found

正式 Lite 與 Portable 分享版都已包含 ADB。請確認 ZIP 已完整解壓縮，而且沒有只複製
其中的 `app` 資料夾。防毒軟體若隔離了 `adb.exe`，請先還原檔案後再試。

### Lite 版下載失敗

確認電腦可以連線到網路，並重新雙擊 `start-bot.cmd`。如果公司的防火牆或防毒軟體
阻擋下載，請改用 Portable 完整免安裝版。

### 視窗一閃就關閉

不要直接執行 `app` 裡面的 Python 檔案。請從最外層資料夾雙擊 `start-bot.cmd`。
若仍失敗，保留視窗最後顯示的錯誤文字，或產生診斷包交給維護者。

## 十、產生診斷包

Bot 沒有正常運作時：

1. 在控制視窗輸入 `E`。
2. 系統會產生不含遊戲截圖的診斷 ZIP。
3. 診斷檔位於：

```text
app\diagnostics
```

4. 將最新的 `dino-diagnostic-*.zip` 傳給維護者分析。

診斷包會遮蔽常見 Token、密碼、電子郵件與使用者路徑。預設不包含遊戲畫面；只有在
診斷工具中明確選擇加入截圖時才會擷取。

## 十一、建議的分享說明

可將下面這段直接貼給第一次使用的人：

```text
1. 下載 Portable 完整免安裝版並完整解壓縮到 D 槽。
2. 開啟模擬器與 Dino Mutant，將解析度設為直向 900 × 1600。
3. 到模擬器的設定或問題診斷中找到 ADB Port。
4. 雙擊 start-bot.cmd。
5. 第一次輸入 ADB Port，例如 MuMu 顯示 16384 就輸入 16384。
6. 等待環境檢查完成，Bot 就會開始運作。
7. 之後啟動直接按 Enter 沿用設定；要換 Port 請在控制視窗按 M。
8. 要停止請在控制視窗按 Q。
```

## macOS 補充

Apple Silicon macOS 使用 BlueStacks Air。啟用 Android Debug Bridge，將遊戲設為
直向 `900 × 1600`，並在 Finder 雙擊：

```text
start-bot.command
```

停止時雙擊：

```text
stop-bot.command
```

macOS 版本會使用本機 Python 建立獨立執行環境；Windows 的 Lite／Portable 套件與
`start-bot.cmd` 說明不適用於 macOS。
