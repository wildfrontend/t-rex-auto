# 數字字模(Phase B/C 共用)

`src/dino_bot/digits.py` 的 `DigitReader` 載入本資料夾:每個 PNG 是一個
字形的黑底白字二值裁切,檔名即字元(`slash.png` → `/`,`colon.png` → `:`,
其餘檔名必須是單一字元)。載入時會 resize 到統一尺寸再二值化,
所以 HUD 大字與卡片小字可共用同一套。

來源(900×1600 MuMu 截圖庫,2026-08-01 裁切):

| 字元 | 來源畫面 | 區域 |
| --- | --- | --- |
| `2` `8` `/` `3` `5` `0` | 洞穴視角主頁面 `MuMu12-20260731-125225.png` | 左上 HUD「282/350」 |
| `7` `6` | 「我的巢」`MuMu12-20260731-121106.png` | 卡片攻擊值「276」 |
| `1` | 同上 | 卡片速度值「1」 |
| `4` `9` | 同上 | 卡片標題「Lv429」數字部分 |

注意:

- 判讀區域必須裁到**只含數字(與 `/`)**——手繪字母會被讀成
  形似的數字(`o` 就是 `0`),不會回傳 `None`。防呆靠呼叫端的
  結構驗證(如 `read_fraction` 檢查分母 350)。
- 離線回歸:`tests/test_digits.py` 用 `tests/fixtures/hatch/` 的
  真實截圖裁切驗證(對應測試計畫 T6 的離線部分)。
- 倒數計時的 `:` 尚未裁(Phase B/C 流程不讀倒數);需要時補
  `colon.png` 即可。
